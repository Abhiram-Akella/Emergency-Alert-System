🚨 Emergency Alert & Response System
A real-time web application that allows users to report emergencies, notify nearby people, and alert responders instantly based on live location.

🔧 Tech Stack
Backend: Node.js, Express.js

Database: MongoDB with Mongoose

Frontend: React.js, Tailwind CSS

Auth: JWT (for login, register, and password reset)

🔑 Features
Report emergencies with live location

Distress button without login

Auto-assignment of nearest responders

Bulk notifications to nearby users

Password reset using secure JWT token
